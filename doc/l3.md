# Отчёт о выполнении ЛР№3

## Наименование работы

Формирование спецификации OpenAPI.
Преподаватель: Фетисов М.В.

Студент группы ИУ6-21М Кузнецова Мария Эдуардовна.

## Описание задания

Задача № 6: "Robots ".

Создание роботов-насекомых является трудоемкой задачей.Инженеры занимаются проектированием схем в чертежных средах, разрабатывают компоненты для сборки роботов с помощью станков. Программисты отвечают за написание кода для программного обеспечения, которое управляет роботами. Дизайнеры создают внешний вид робота с помощью программных сред. Биологи изучают модель поведения насекомого и отражают результаты в отчетах. Наконец, специалисты по бионике описывают поведение насекомого в виде дифференциальных уравнений, которые программисты добавляют в программное обеспечение.

## Спецификация OpenAPI

Спецификация OpenAPI сформирована в папке `oas` проекта.

## Выводы

1. Разработана **OpenAPI спецификация** (YAML, версия 3.0.0) для API самого **робота-жука** сельскохозяйственного назначения

2. Все эндпоинты соответствуют **пользовательским историям из ЛР2**:
   - `GET /status` — получение текущего состояния
   - `POST /move` — управление движением (ENG-01-001, BNC-02-001)
   - `GET /route` — получение маршрута (SW-03-002)
   - `GET /camera/photo` и `POST /camera/detect` — обнаружение вредителей (BIO-02-002, SW-03-003)
   - `GET /battery` — контроль заряда (SW-03-001)
   - `POST /maintenance/battery` — замена батареи (ASM-04-002)
   - `POST /reset` — сброс настроек (ASM-04-001)

3. Описаны **8 эндпоинтов**, покрывающих функциональность:
   - статус (1)
   - движение (1)
   - маршрут (1)
   - камера и детекция (2)
   - батарея (1)
   - обслуживание (1)
   - сброс (1)

4. Определены **схемы данных** для ответов и запросов

5. Задокументированы **HTTP status codes** (200, 400)

**Изученные технологии:** OpenAPI, REST API, YAML, Design API First.
